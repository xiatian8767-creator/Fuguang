# 浮光 2.1：账号、会员和独立部署

云端来源为《完成APK发布》中的 `xiatian8767-creator/ParallaxWallpaper`，保留中文相册、深度缓存、方向修正、陀螺仪/拖动预览和动态壁纸。本地工作目录为 `C:\Users\15072\Desktop\浮光`。

## 用户规则

- 新生成需要登录联网；原图、深度图和相册始终在手机本地，不上传服务器。
- 普通用户每个北京时间自然周10次，每周一00:00恢复，不结转。成功生成才扣次；查看、删除、重命名、调整预览、设壁纸不扣次。
- 月卡1个日历月，年卡12个日历月；从当前有效到期日继续叠加，到期后恢复普通用户规则。月末按目标月份的最后一天对齐。
- 永久卡无到期时间；已有永久会员再兑换会拒绝，兑换码不消耗。无在线支付。
- 兑换码随机生成，仅一次使用，完整码只在生成时返回，数据库只存哈希。后台可导出本次TXT、查看尾号和停用未用码。
- 服务端事务预留名额，成功确认幂等扣次；最多3个并发任务。失败释放，异常中断的预留30分钟后释放。
- 成功生成但确认断网时，照片临时隐藏，重开应用或关闭账号面板后重试确认。按原账号核对，避免切换用户误删。若从未确认且超过30分钟，删除未授权副本并提示重新导入，原图不受影响。
- 这是官方客户端的服务端额度控制。本地推理模型随APK分发，不能承诺阻止被修改的第三方客户端绕过本地逻辑。

## 管理后台与推广

官网 `https://fuguang.startimetable.xyz/`，后台 `/admin/`，API `/api/`。

管理员密码在本机 `private/管理员凭据.txt`，不提交Git；服务器 `.env` 仅存密码哈希。更换密码哈希后需重建API容器，旧管理员会话可在数据库中撤销。管理员会话8小时，Secure/HttpOnly/SameSite Cookie，写操作需CSRF。用户支持搜索、停用、重置密码、调整会员；重置密码/停用撤销该用户会话。操作记录保存在独立审计表中。

“App 弹窗”支持文字和官网H5，标题、正文、按钮、目标versionCode、北京时间起止、全部/指定用户、尺寸、一次/每天/每周/每次进入。客户端每次启动最多展示一个活动；达到目标版本不展示。新活动默认停用，先指定自己的用户ID测试。编辑保留原活动展示记录；重新独立投放应新建活动。H5加载成功才记已展示；失败关闭弹窗不阻塞使用。网页不启用JS、不注入原生接口、禁止文件访问和混合内容。仅允许浮光官网HTTPS链接，下载交给浏览器。

## 独立资源

服务器目录 `/opt/fuguang`，Compose项目 `fuguang`，镜像 `fuguang-api:2.1.0`，SQLite卷 `fuguang_fuguang-data`，API仅回环 `127.0.0.1:18081`。数据、账号、管理员和活动均独立于 `/opt/xingke-v2`、`/opt/xingke-download`。

共享服务器的80/443网关：按Host/SNI转发浮光子域名，保留Star Orbit原路由及原IP证书。浮光证书在 `/etc/letsencrypt/live/fuguang.startimetable.xyz`。额外挂载和网络由 `deploy/edge.override.yaml` 声明，未来重建原443网关时需同时带上该文件；否则浮光域名入口会丢失，数据仍保留。

部署API：在 `/opt/fuguang` 运行 `docker compose build api && docker compose up -d api`。下载APK放在 `/opt/fuguang/downloads/Fuguang-3D-Album.apk`，从独立目录只读挂载。证书续期为 `fuguang-certificate.timer`；更新服务不覆盖续期脚本或密钥。

数据备份：通过Python sqlite3的 `Connection.backup` 从运行中的数据库做一致性备份，不直接复制正在写入的数据库文件。保留服务器 `.env`、证书及本地发布签名。恢复时先停API再还原卷，并保留原权限10001:10001。

## 本地运行和构建

Android SDK来自TIM的API35/Build Tools35.0.0，本项目 `.local/android-sdk` 按Gradle标准目录布局复用；JDK17和Gradle8.9放在 `.local/tools`。TIM本身的Java/WebView打包脚本不能直接构建Kotlin/Compose。模型使用原项目Depth Anything V2 ViT-S量化模型，下载后位于assets，已从Git忽略。

正式签名构建：`powershell -ExecutionPolicy Bypass -File scripts/build-local.ps1 -Release`。首次自动创建本项目独立签名，保存在 `private/fuguang-release.jks` 和 `private/signing-password.txt`，请备份，后续升级必须沿用。本版关闭调试、暂不混淆，构建并发限制为2以控制本机内存。它与云端旧调试版签名不同，旧测试版需先保留原照片并卸载后安装；不能把新包描述成可覆盖旧云端包。

后端运行：安装 `backend/requirements.txt` 后运行 `python -m uvicorn backend.app:app --host 127.0.0.1 --port 18765`。本地后台HTTP调试需 `FUGUANG_LOCAL=1`，生产环境禁止设置。管理员哈希可由 `backend.app.password_hash` 生成，真实密码不放命令行。

验证入口：`python -m unittest backend.test_app -v`；`qa/pages.cjs` 对桌面/手机官网、管理登录和活动保存做真实浏览器检查，输出位于 `qa/output`。现有 `scripts/test_gl_render.py` 需要Linux EGL，Android仪器测试保留在 `app/src/androidTest`。最终完成情况与限制见 `docs/交付状态.md`。
