# 浮光 · 3D相册 2.0

普通照片导入后，在本机生成深度并保存；之后离线查看无需重复推理。相册支持重命名、删除、逐图保存立体强度、拖动/陀螺仪预览、视角回正和沉浸查看。每张照片都能设为动态壁纸，删除相册项不会删除手机原图或已应用的壁纸。照片与深度保存在应用私有目录；卸载会移除相册数据。

## 延迟割裂与倒置修复

- 深度图宽为 518，单通道每行 518 字节。默认 GL_UNPACK_ALIGNMENT=4 会把步长解释为 520，深度逐行漂移并越界读取。上传期间改为 1，随后恢复为 4。
- 移除 abs(mod(uv, 2)-1) 的错误镜像表达式；该式在 [0,1] 范围得到 1-uv，使画面水平及垂直翻转。改为边缘钳制和小幅预留边界。
- 使用 GL_LINEAR + CLAMP_TO_EDGE，避免 ES 2.0 非二次幂纹理启用 mipmap 导致不完整。
- 导入时应用照片 EXIF 旋转/镜像信息，让显示图与模型输入方向一致，并限制导入图尺寸。
- 保存深度并在查看/设置壁纸时复用，图像与对应深度一起上传，避免异步切换图像时混用旧深度。
- 深度较大表示更近，修正原注释和视差方向；限制最大位移，减轻单图遮挡区域的拉伸。
- 所有 EGL 操作固定在各自渲染线程；后台暂停绘制与传感器。共享 ORT 环境不再随单个会话关闭。

## 验证

`EGL_PLATFORM=surfaceless python3 scripts/test_gl_render.py` 使用 Mesa EGL 执行实际生产 GLSL，验证方向、268324 个深度像素的上传结果，并重现旧版对齐错误。

GitHub Actions 构建 APK、运行 lint，并在 Android 模拟器中用真实 ONNX 模型导入带 EXIF 旋转的测试照片，校验缓存、查看超过 6 秒、沉浸模式、切回前台及相册持久化。验证截图随 device-test-results 产物保存。模拟器验证不替代具体手机的陀螺仪和厂商壁纸兼容性测试。

APK 为测试签名，构建缓存会保留新版的调试密钥。最早的 1.0 构建没有保留密钥；若旧版无法覆盖安装，需要先卸载旧版。
